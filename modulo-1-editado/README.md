# Módulo 1 – Efeito Caixa d'Água (EDITADO)

Vídeo final: 1920×1080, 30 fps, 19 min 38 s, 328 MB. Como o GitHub limita arquivos a 100 MB, ele está dividido em 4 partes.

## Como baixar e juntar
1. Baixe os 4 arquivos `Modulo1-EDITADO.mp4.part0` … `part3` para a **mesma pasta** (clique em cada um → botão **Download** / "View raw").
2. Baixe também `JUNTAR-WINDOWS.bat` (Windows) ou `juntar-mac.command` (Mac) para a mesma pasta.
3. Dê dois cliques no arquivo de juntar. Ele gera `Modulo 1 - Efeito Caixa dAgua - EDITADO.mp4`.
4. Pode apagar as partes depois.
