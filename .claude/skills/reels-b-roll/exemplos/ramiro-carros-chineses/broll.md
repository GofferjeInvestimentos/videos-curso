# B-roll do exemplo (Pexels, licença livre — não vai no repositório por tamanho)

Baixar pra `broll/` ao lado do `roteiro.json`, UM POR VEZ (em paralelo o Pexels devolve vazio):

    curl -sSL -A "Mozilla/5.0" -o broll/<nome>.mp4 "https://www.pexels.com/download/video/<ID>/?h=1280&w=720"
    (se vier vazio: trocar por ?h=720&w=1280)
